# AC Custom Labs Landing Skill v2

A portable interactive landing-page skill for Antigravity/Gemini-style
coding agents.

## Purpose

This skill adapts the interaction ideas from the supplied landing-page
prompts to the real AC Custom Labs website without copying their
identity, assets, fake metrics, partner names, or product copy.

The core reference patterns are:

1.  Fintech-style cinematic hero + CTA/marquee composition
2.  Liquid-glass creative agency motion + fading video + blur/reveal +
    magnetic CTA
3.  3D creator portfolio motion + scroll image rows + magnetic
    interaction + stacked work cards
4.  Futuristic systems page motion + cinematic video + scramble text +
    spring navigation + scroll-linked sections

The supplied material also included an editorial museum-style
interaction system. Its useful patterns are retained only as optional
editorial references.

## Commands

``` text
/ac-custom-labs-landing plan
/ac-custom-labs-landing build
/ac-custom-labs-landing polish
/ac-custom-labs-landing audit
/ac-custom-labs-landing security
/ac-custom-labs-landing content
/ac-custom-labs-landing portfolio
/ac-custom-labs-landing inspire
```

## Install

Copy this folder into the project skill location used by your
Antigravity setup, typically:

``` text
.agents/skills/ac-custom-labs-landing/
```

The skill is designed to inspect the existing AC Custom Labs docs, logo,
code, installed dependencies, skills, and MCPs before implementation.

## Important

The skill treats the existing AC Custom Labs project documentation as
the source of truth. Reference prompts are used only to inspire
interaction patterns.
