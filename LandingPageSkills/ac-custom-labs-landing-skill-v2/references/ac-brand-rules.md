## Voice

Direct, human, specific, professional, confident.

Avoid AI-agency filler and unsupported claims.

## Banned wording

bespoke explore transform in the heart of harness delve rooted elevate
unparalleled curated timeless immerse discover crafted seamless
reimagine world-class iconic

## Punctuation

Never use the em dash character: ---

Prefer: - periods - commas - parentheses - en dash: --

## Security

Public copy is fine in the frontend.

Secrets are not.

Never commit: - API keys - private tokens - database credentials -
webhook secrets - OAuth secrets - JWT secrets - deployment credentials -
private certificates - service-account files
