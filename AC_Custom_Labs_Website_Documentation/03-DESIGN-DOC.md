# AC CUSTOM LABS --- DESIGN DOCUMENT

## 1. Brand Analysis

The supplied logo has a highly recognizable minimal technology
aesthetic.

### Logo characteristics

-   Black background
-   White geometric `AC`
-   Red `Custom`
-   White `Labs`
-   Red curved underline
-   Sans-serif typography
-   Strong horizontal composition
-   High contrast
-   Minimal decoration

The website should extend these principles rather than introduce an
unrelated visual identity.

------------------------------------------------------------------------

## 2. Brand Personality

**CUSTOM · TECHNICAL · BOLD · PRECISE · MODERN**

The company should look like a product engineering studio, not a generic
digital-marketing template.

------------------------------------------------------------------------

## 3. Color System

### Core

``` css
--black: #050505;
--black-soft: #0B0B0D;
--surface: #111114;
--surface-2: #18181B;

--white: #F7F7F7;
--muted: #A1A1AA;

--red: #FF1738;
--red-dark: #C90F28;
```

### Usage

Black/dark surfaces: **70--80%**

White: **15--25%**

Red: **5--10%**

Red should be an accent, not a full-page background.

------------------------------------------------------------------------

## 4. Typography

### Headings

Recommended: - Space Grotesk - Sora - Manrope

### Body

Recommended: - Inter - Geist

Use: - Tight large headings - Short paragraphs - High line-height for
body text

------------------------------------------------------------------------

## 5. Visual Language

Use:

-   Strong grids
-   Thin borders
-   Large typography
-   Red accent lines
-   Black surfaces
-   White text
-   Subtle glow
-   Technical labels
-   Monospace metadata where useful

Avoid: - Excessive gradients - Generic stock-business illustrations -
Overuse of rounded cards - Excessive glassmorphism - Purple/blue startup
aesthetics

------------------------------------------------------------------------

## 6. Hero

### Layout

Large headline:

**WE BUILD DIGITAL PRODUCTS THAT WORK.**

Small eyebrow:

`AC CUSTOM LABS / DIGITAL ENGINEERING`

Supporting:

**Apps, software, websites and SEO solutions built around your
business.**

Buttons:

**START A PROJECT**

**VIEW OUR WORK**

Visual:

-   Abstract red technical grid
-   Code-like patterns
-   Project screenshots
-   Animated lines
-   Subtle red glow

Do not use distracting 3D objects unless they support the brand.

## 16. Brand Rule

**Red is the signal. Black is the environment. White is the
information.**

This should be the guiding visual rule throughout the website.
